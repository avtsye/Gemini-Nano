# Gemini Nano Local Chat

תוסף Chrome מינימלי שמדגים שימוש ב-Gemini Nano המובנה בדפדפן דרך Prompt API — ללא API key וללא שרת חיצוני עבור יצירת התשובה.

## מה יש כרגע

- ממשק צ'אט בעברית וב-RTL.
- שימוש ב-`LanguageModel` של Chrome וב-`promptStreaming()`.
- זיהוי מצב המודל: זמין / דורש הורדה / בהורדה / לא זמין.
- הצגת התקדמות הורדת המודל.
- תמיכה בעברית באמצעות Translator API המקומי של Chrome:
  - עברית → אנגלית לפני השליחה ל-Gemini Nano.
  - אנגלית → עברית עבור התשובה.
- ניקוי session ושיחה בלחיצה אחת.
- ללא API key.

## התקנה

1. הורד או שכפל את המאגר.
2. פתח ב-Chrome:
   `chrome://extensions`
3. הפעל **מצב מפתח**.
4. לחץ **טעינת פריט unpacked / Load unpacked**.
5. בחר את תיקיית המאגר.
6. לחץ על סמל התוסף בסרגל Chrome.
7. שלח הודעה. אם המודל עדיין לא קיים במחשב, Chrome יוריד אותו.

## דרישות

- Chrome 138 ומעלה עבור Prompt API בתוספים.
- מחשב שולחני נתמך.
- בפעם הראשונה ייתכן ש-Chrome יצטרך להוריד את המודל המקומי.
- Prompt API תומך ישירות כרגע באנגלית, יפנית, ספרדית, גרמנית וצרפתית; התוסף מוסיף שכבת תרגום מקומית לעברית באמצעות Translator API.

## פרטיות

ה-Prompt API נועד להריץ את המודל בתוך Chrome במכשיר המקומי. גם תרגום העברית בתוסף נעשה דרך Translator API המובנה של Chrome.

## מבנה

- `manifest.json` — הגדרות Manifest V3.
- `popup.html` — ממשק התוסף.
- `popup.css` — עיצוב.
- `popup.js` — Prompt API, streaming, הורדת מודל ותרגום.
