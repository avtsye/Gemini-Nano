# Gemini Nano Local Workspace

סביבת AI מקומית ל-Chrome המבוססת על **Gemini Nano / Chrome Built-in AI**. המטרה היא להפוך את ה-Prompt API מכלי הדגמה לעוזר יום-יומי אמיתי — בלי API key ובלי שרת AI חיצוני עבור יצירת התשובה.

## גרסה 0.5.0

הפרויקט עבר מתיבת popup פשוטה ל-**Local AI Workspace** מלאה בתוך Side Panel של Chrome.

### צ'אט מקומי

- Gemini Nano דרך `LanguageModel`.
- Streaming בזמן יצירת התשובה.
- תמיכה בעברית באמצעות Translator API המקומי.
- עצירת תשובה באמצע.
- סגנון תשובה: תמציתי / מאוזן / מפורט.
- בחירת שפת תשובה.
- System Prompt מותאם אישית.
- מונה תווים וקלט רב-שורות.

### שיחות והיסטוריה

- שיחות מרובות.
- שמירה מקומית ב-`chrome.storage.local`.
- חיפוש בשיחות.
- שמות אוטומטיים לשיחות.
- שינוי שם ידני.
- מחיקת הודעה בודדת.
- שימוש חוזר בהודעה קודמת.
- העתקת תשובה.
- ייצוא שיחה לקובץ Markdown.

### AI על העמוד הנוכחי

התוסף יכול לקרוא את הטקסט הגלוי של הטאב הפעיל, לצרף אותו כהקשר ולבצע:

- סיכום עמוד.
- חילוץ נקודות מפתח.
- הסבר בשפה פשוטה.
- תרגום לעברית.
- שאלות חופשיות על העמוד.
- קריאת טקסט מסומן בלבד.

מטעמי יעילות, ההקשר הנשלח למודל מוגבל כרגע ל-14,000 תווים ראשונים של הטקסט שחולץ.

### תפריט קליק ימני

בסימון טקסט בעמוד ניתן להשתמש בתפריט ההקשר של Chrome כדי:

- לשאול את Gemini Nano על הטקסט.
- לסכם את הטקסט.
- להסביר את הטקסט.

הבקשה מועברת ל-Side Panel.

### פרטיות

- אין צורך ב-API key.
- Gemini Nano רץ דרך מנגנון ה-Built-in AI של Chrome.
- היסטוריית השיחות נשמרת ב-Chrome המקומי.
- תרגום עברית/אנגלית נעשה דרך Translator API של Chrome.
- תוכן עמוד נקרא רק כאשר המשתמש מבקש לצרף/לנתח אותו.

## התקנה

1. הורד או שכפל את המאגר.
2. פתח `chrome://extensions`.
3. הפעל **מצב מפתח**.
4. לחץ **Load unpacked / טעינת פריט unpacked**.
5. בחר את תיקיית המאגר.
6. לחץ על אייקון התוסף.
7. בחר **פתח סביבת עבודה**.

בפעם הראשונה Chrome עשוי להוריד את Gemini Nano ואת מודלי התרגום המקומיים.

## דרישות

- Chrome 138 ומעלה.
- מחשב שולחני וחומרה הנתמכים על-ידי Chrome Built-in AI.
- זמינות Prompt API / Translator API עשויה להשתנות לפי גרסת Chrome, מערכת ההפעלה והחומרה.

## הרשאות

- `storage` — שמירת שיחות והגדרות מקומית.
- `activeTab` + `scripting` — קריאת העמוד הפעיל רק בעקבות פעולת המשתמש.
- `sidePanel` — סביבת העבודה הקבועה.
- `contextMenus` — פעולות AI על טקסט מסומן.

## מבנה הפרויקט

- `manifest.json` — Manifest V3 והרשאות.
- `background.js` — תפריט קליק ימני והעברת בקשות ל-Side Panel.
- `popup.html/css/js` — מסך פתיחה ובדיקת זמינות.
- `sidepanel.html/css/js` — סביבת העבודה הראשית.
