# Gemini Nano Local Workspace

סביבת AI מקומית ל-Chrome המבוססת על Gemini Nano / Chrome Built-in AI, ללא API key.

## גרסה 1.1.0

גרסה זו הופכת את התוסף מסביבת צ'אט בסיסית לעוזר מקומי מלא לדפדפן.

### UX/UI 1.1
- סרגל עליון קומפקטי עם סטטוס מקומי ו-Context מינימליים.
- תפריט + מאוחד לעמוד, טקסט מסומן, קבצים וצילום מסך.
- תפריט ⋯ לפעולות משניות.
- קיבוץ שיחות לפי מועדפים / היום / אתמול / השבוע / ישן יותר.
- מצב ריק חדש עם פעולות מומלצות והסברי קיצורי דרך.
- רינדור Markdown בטוח לתשובות, כולל קוד, רשימות וציטוטים.
- Toasts לפעולות קצרות במקום הודעות שחוסמות את הזרימה.
- Typing indicator טבעי יותר.
- שיפור RTL, hover/focus, מסכים צרים ו-prefers-reduced-motion.
- מסך אבחון שכבת שפה שמציג תרגום ישיר, מסלולי pivot והבקשה המנורמלת.
- קיצורים: Ctrl+K לפקודות, / למעבר לשדה ההקלדה, Escape לסגירת תפריטים.

### שחזור כוונה רב-מסלולי
- הבקשה בעברית מתורגמת ישירות לאנגלית.
- כאשר חבילות התרגום כבר זמינות, נוצרים גם מסלולי pivot דרך גרמנית, ספרדית וצרפתית ואז חזרה לאנגלית.
- Gemini Nano משווה בין המסלולים ומעדיף משמעות עקבית בין כמה תרגומים בלתי תלויים.
- מקטעים וצירופי מילים קצרים משמשים רק לפתרון עמימות, לא ליצירת כוונה חדשה.
- אין כללים קשיחים למילים עבריות מסוימות.

### נרמול כוונה כללי
- הוסרה שכבת כללים קשיחים בעברית.
- לאחר תרגום עברית→אנגלית, Gemini Nano מבצע שלב קצר ונפרד של נרמול סמנטי.
- הנרמול שומר על הפעולה המבוקשת, היקף התשובה, פורמט, שלילות ומגבלות — בלי לענות על הבקשה.
- אם הנרמול אינו זמין, המערכת חוזרת אוטומטית לתרגום הרגיל.

### אמינות ואתחול
- כפתור "הכן AI מקומי" להורדה/אתחול מתוך user activation.
- אבחון Prompt API, Translator API, multimodal ופרמטרי המודל.
- בדיקת קצה-לקצה.
- שחזור session במקרה של חריגת context.
- GitHub Actions לבדיקת manifest ותחביר JavaScript בכל push.

### זיכרון ושיחות
- שיחות מרובות.
- שחזור context משיחות קודמות באמצעות modelText פנימי.
- חיפוש בתוך שמות ותוכן שיחות.
- מועדפים והצמדה.
- סינון לפי תיקיות בסיסיות.
- שינוי שם, מחיקה וייצוא Markdown.

### Context חכם
- חלוקת עמודים וקבצים למקטעים.
- דירוג מקטעים לפי רלוונטיות לשאלה.
- שליחת קטעים רלוונטיים במקום חיתוך עיוור.
- מד Context שמציג שימוש אמיתי כאשר Chrome חושף inputUsage/inputQuota, ובאומדן כשלא.
- מצב "אתר חי" שמרענן את העמוד המצורף לפני כל שאלה.

### דפים ארוכים
- סיכום היררכי: סיכום חלקים ולאחר מכן איחוד לסיכום אחד.
- הסבר, נקודות מפתח, תרגום ושאלות על עמוד.

### קבצים ותמונות
- קבצי TXT, Markdown, JSON, CSV, HTML, XML ו-LOG.
- תמונות מקומיות דרך יכולת multimodal של Prompt API.
- צילום מסך של הטאב הפעיל וצירופו לשיחה.
- מספר קבצים/תמונות באותה בקשה.

### עברית
Prompt API עצמו תומך ישירות במספר שפות מוגבל. התוסף משתמש ב-Translator API המקומי של Chrome עבור עברית ↔ אנגלית.
- תרגום קלט.
- תרגום תשובה.
- translateStreaming כאשר הדפדפן תומך בו.

### כלי שיחה
- Regenerate.
- קצר יותר.
- פרט יותר.
- שימוש חוזר בהודעה.
- העתקה ומחיקה.

### פרופילי עוזר
- כללי.
- מתכנת.
- חוקר.
- עורך טקסט.

### שליטה במודל
בתוספי Chrome, כאשר הממשק זמין, ניתן להשתמש ב-`LanguageModel.params()` ובפרמטרים `temperature` ו-`topK`. ההגדרות מוגבלות אוטומטית למקסימום שהדפדפן מדווח.

### Command Palette
לחץ `Ctrl+K` כדי לפתוח פקודות מהירות:
- שיחה חדשה.
- סיכום/הסבר עמוד.
- צירוף עמוד, טקסט, קובץ או צילום מסך.
- הגדרות.
- אבחון.
- ייצוא.

## התקנה
1. פתח `chrome://extensions`.
2. הפעל מצב מפתח.
3. Load unpacked ובחר את תיקיית המאגר.
4. פתח את התוסף ואת סביבת העבודה.
5. אם מוצג "הכן AI מקומי" — לחץ עליו והמתן לסיום.

## דרישות
- Chrome 148+ לגרסה זו, בגלל תמיכה אופציונלית ביכולות multimodal.
- חומרה הנתמכת על-ידי Chrome Built-in AI.
- ייתכן שיידרש מקום משמעותי בדיסק להורדת המודלים המקומיים.

## פרטיות
- ללא API key.
- יצירת התשובות נעשית דרך המודל המקומי של Chrome.
- היסטוריה והגדרות נשמרות ב-`chrome.storage.local`.
- תוכן עמוד נקרא רק לאחר פעולה מפורשת של המשתמש או כאשר "מצב אתר חי" הופעל.
